PAGES LEGALES KYORIN — MODE D'EMPLOI

Fichiers :
- index.html : page d'accueil avec liens
- privacy-policy.html : politique de confidentialité
- terms-of-service.html : conditions d'utilisation

IMPORTANT AVANT PUBLICATION
1. Remplacez TOUS les champs entre crochets.
2. Vérifiez le code réel de Kyorin pour confirmer quelles données sont collectées, où elles sont stockées, qui peut y accéder et combien de temps elles sont conservées.
3. Supprimez toute fonctionnalité ou pratique qui ne correspond pas au bot.
4. Ajoutez un contact que les utilisateurs peuvent réellement joindre.
5. Ces modèles sont une base pratique, pas un avis juridique ni une garantie de conformité.

PUBLICATION GITHUB PAGES
1. Sur GitHub, créez un dépôt public nommé kyorin-legal-pages.
2. Ouvrez le dépôt, cliquez sur Add file > Create new file.
3. Créez index.html, collez le contenu de index.html du dossier, puis Commit changes.
4. Recommencez pour privacy-policy.html et terms-of-service.html.
5. Ouvrez Settings > Pages.
6. Sous Build and deployment, choisissez Deploy from a branch.
7. Choisissez la branche main et le dossier /(root), puis Save.
8. Attendez la publication et ouvrez l'adresse indiquée dans Settings > Pages.
9. Testez les trois pages dans une fenêtre privée avant de mettre les liens dans Discord.

Les URL auront généralement cette forme :
https://VOTRE-NOM-GITHUB.github.io/kyorin-legal-pages/
https://VOTRE-NOM-GITHUB.github.io/kyorin-legal-pages/terms-of-service.html
https://VOTRE-NOM-GITHUB.github.io/kyorin-legal-pages/privacy-policy.html

Remplacez VOTRE-NOM-GITHUB par votre nom de compte GitHub exact. Ne collez pas ces exemples tels quels.
